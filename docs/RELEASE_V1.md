# V1.0.0 release checklist

The V1 baseline was manually accepted on Microsoft Edge/Windows before the release cleanup.

## Accepted

- Persistent obscuring across refresh and browser restart.
- Manual element selection.
- SPA and dynamic DOM handling.
- Same-origin iframe support.
- Multiple saved rules.
- Single-rule and global enable/disable/reactivation.
- Explicit rule deletion.
- Safety-first matching with no observed false positives during V1 acceptance.
