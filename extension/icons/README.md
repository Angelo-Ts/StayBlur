# StayBlur extension icons

The browser UI icons use the canonical StayBlur browser-window + lock mark and blue-to-violet gradient.

`stayblur-icon.svg` is the editable source artwork. `stayblur-icon-128.png` is the PNG asset used by the Manifest V3 `icons` and `action.default_icon` entries so Edge can show StayBlur in its Extensions menu and toolbar.
