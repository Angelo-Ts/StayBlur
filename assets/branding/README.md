# StayBlur brand assets

These assets are the canonical StayBlur visual identity for the extension and repository.

- `stayblur-icon-16.png` — browser action icon, 16×16
- `stayblur-icon-32.png` — browser action icon, 32×32
- `stayblur-icon-48.png` — browser action icon, 48×48
- `stayblur-icon-128.png` — extension/store icon, 128×128
- `stayblur-wordmark.png` — transparent StayBlur wordmark

Primary visual language: a protected browser window with a lock, using the blue → violet gradient already associated with StayBlur.
