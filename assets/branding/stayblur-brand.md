# StayBlur identity

## Core mark

The StayBlur mark combines a browser window and a lock: it communicates **web content protection** without suggesting that the underlying site is modified.

## Color direction

The primary gradient moves from deep blue through indigo to violet. UI states should use this gradient family for identity, while destructive actions remain visually distinct.

## Interaction states

- **StayBlur / normal:** blue identity
- **Selection active:** solid red `Termina selezione` action, deliberately distinct from the white/red-outline destructive `Elimina` controls
- **Rule focus:** blue outline around the selected saved element
